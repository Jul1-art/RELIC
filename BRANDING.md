# RELIC identity

The orbital emblem and central four-point star are based on the official logo reference supplied by the project owner. `assets/relic-logo-v1.png` is a clean, AI-assisted reproduction of that chat reference, rather than the original uploaded master. The square PNGs are install-icon derivatives with a black background and safe padding.

Use the same mark in application headers, loading states, the film ending, and installed-app identity. Replace these derivatives with the owner's original production master when that file is available; preserve the owner's geometry and do not redesign the emblem.
